# Python Daily Practice

Organized from the uploaded `practice.ipynb` without modifying code or outputs.

## Dating policy
- Folders with dates are based on date headings explicitly written in the original notebook.
- Cells following a date heading are grouped under that heading **until the next heading or an identified undated transition**. This does not prove every cell was authored on that date.
- `Undated/01_before_20_September.ipynb` contains the first 42 cells, which have no date heading.
- `Undated/02_OOP_and_decorators.ipynb` contains cells 78–118 (zero-based), where no reliable day heading appears; do not assume all these cells were written on September 23.
- `date_mapping.csv` maps each split notebook to the original cell positions.
- `practice_original.ipynb` is an exact backup of the uploaded notebook.
- Empty or unfinished code cells are retained.

## Upload to GitHub
Create a repository named `Python-Daily-Practice`, then upload the extracted folders and files using **Add file → Upload files** (or Git). Keep the dated folders and `Undated` folder as-is.
